# Sensitivity Matrix & Coefficient of Importance (CoI)

The **Sensitivity Matrix** provides a fast, model-independent screening assessment of how strongly each input factor influences each target response. Using the **Spearman Coefficient of Importance ($\operatorname{CoI}$)** expressed as a normalized percentage ($0\%$ to $100\%$), this plot ranks input variables by impact prior to training surrogate models.

<KeyTakeaways title="Quick Guide & Key Takeaways">
- **Dimensionality Reduction (Factor Fixing)**: Parameters contributing $< 2\%$ across all target responses can frequently be frozen at baseline values, simplifying subsequent training and optimization.
- **Model-Free Screening**: Because $\operatorname{CoI}$ is computed directly on empirical or simulation samples using rank statistics, it does not depend on surrogate architecture or suffer from model fitting errors.
- **Multi-Output Comparison**: High-dimensional datasets immediately expose which specific inputs control which physical performance criteria.
</KeyTakeaways>

## How to Read This Plot

### 1. Axes & Columns
- **Vertical Axis (Rows)**: Design parameters and input variables ($x_1, \dots, x_d$).
- **Horizontal Axis (Columns)**: System responses ($y_1, \dots, y_p$).
- **Column Normalization**: Every vertical column sums to exactly $100\%$. The values quantify the relative share of response variance driven by each input.

### 2. Reading Color Saturation & Percentages
- **Deep Blue Cells ($\operatorname{CoI} \ge 50\%$)**: Primary driving factors. These parameters govern the output and should be treated as core variables in optimization.
- **Medium Blue Cells ($10\% \le \operatorname{CoI} < 50\%$)**: Secondary influential factors that provide fine-tuning capability.
- **Pale / White Cells ($\operatorname{CoI} < 2\%$)**: Negligible factors. Variations in these inputs have little to no measurable effect on that response.

### 3. Actionable Interpretation Rules
1. **Factor Prioritization**: Focus optimization on the top 1 or 2 variables per response (e.g., $x_1$ for Peak Stress, $x_2$ for Efficiency).
2. **Factor Fixing**: If an input factor scores $< 2\%$ across *all* columns (such as $x_4$ Fillet Radius with $1.4\%$ and $1.2\%$), it can be fixed to a constant nominal value. This reduces problem dimensionality without loss of model accuracy.
3. **Decoupled Control**: Notice in Figure 1 that $x_1$ controls Stress while having little influence on Efficiency ($5.3\%$), while $x_2$ controls Efficiency while having little influence on Stress ($4.1\%$). This indicates that the two physical responses can be tuned almost independently.

## Mathematical Formulation

Let $d$ denote the number of input design variables and $p$ denote the number of responses. For response $y_m$ ($m = 1, \dots, p$), the Spearman rank correlation with input factor $x_j$ ($j = 1, \dots, d$) is $\rho(x_j, y_m)$.

The **Spearman Coefficient of Importance ($\operatorname{CoI}$)** expresses the relative proportion of monotonic variance attributed to input factor $x_j$ for output $y_m$:

$$\operatorname{CoI}_j^{(m)} = \frac{\rho^2(x_j, y_m)}{\sum_{k=1}^d \rho^2(x_k, y_m)} \times 100\%$$

Key properties:
1. $\sum_{j=1}^d \operatorname{CoI}_j^{(m)} = 100\%$ for every response $y_m$.
2. $\operatorname{CoI}_j^{(m)} \ge 0$ for all factors.
3. The metric preserves monotonic rank invariance even when responses exhibit heavy power-law or logarithmic tails.
