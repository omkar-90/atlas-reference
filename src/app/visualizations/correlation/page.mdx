# Correlation Matrix & Multicollinearity Diagnostics

The **Correlation Matrix** displays pairwise coefficients across all input design factors and output responses. In surrogate modeling, identifying linear and monotonic relationships between variables is essential for spotting multicollinearity, eliminating redundant design parameters, and understanding direct physical couplings.

<KeyTakeaways title="Quick Guide & Key Takeaways">
- **Multicollinearity Flagging**: Pairs of inputs with $|r| > 0.85$ indicate strong collinearity. In linear and polynomial regression, this inflates parameter variance and causes numerical instability.
- **Monotonic vs. Linear Dependencies**: Both Pearson ($r$) and Spearman rank ($\rho$) metrics are used to capture linear and monotonic nonlinear physical phenomena.
- **Input-Output Screening**: Variables with $|r| > 0.6$ against target responses highlight the primary drivers of system performance.
</KeyTakeaways>

## How to Read This Plot

### 1. Axes & Cell Positions
- **Rows & Columns**: Every parameter (inputs $x_1, x_2, \dots$ and outputs $y_1, y_2, \dots$) is mirrored along both vertical and horizontal axes.
- **Diagonal Elements**: The top-left to bottom-right diagonal represents each variable compared to itself, always equaling $+1.00$.
- **Symmetry**: The matrix is symmetric ($r_{ij} = r_{ji}$), meaning the upper-right triangle contains the same values as the lower-left triangle.

### 2. Reading Color Scales & Magnitudes
- **Deep Blue ($r \to +1.0$)**: Strong positive association. When parameter $A$ increases, parameter $B$ consistently increases.
- **Deep Red ($r \to -1.0$)**: Strong negative association. When parameter $A$ increases, parameter $B$ decreases.
- **Neutral Gray / Off-White ($r \approx 0$)**: No linear relationship. Variations in one variable do not systematically shift the other.

### 3. What to Look For
1. **Input-Input Independence ($\mathbf{R}_{xx}$)**: In well-designed Latin Hypercube or Sobol sampling plans, inputs should have near-zero correlations ($|r| < 0.15$). High off-diagonal correlation between two inputs indicates sampling bias or coupled physical constraints.
2. **Dominant Response Drivers ($\mathbf{R}_{xy}$)**: Look for cells in the input-output blocks with deep color saturation ($|r| > 0.6$). In Figure 1, Radius ($x_1$) is strongly linked to Peak Stress ($r = 0.82$), while Angle ($x_2$) drives Efficiency ($r = 0.71$).
3. **Competing Objectives ($\mathbf{R}_{yy}$)**: Negative correlation between responses ($y_1$ vs. $y_2$, $r = -0.68$) immediately signals a Pareto trade-off: minimizing stress conflicts with maximizing efficiency.

## Mathematical Formulation

### Pearson Product-Moment Correlation ($r$)

For two continuous variables $\mathbf{x} = \{x_1, \dots, x_N\}$ and $\mathbf{y} = \{y_1, \dots, y_N\}$:

$$r_{xy} = \frac{\sum_{i=1}^N (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^N (x_i - \bar{x})^2} \sqrt{\sum_{i=1}^N (y_i - \bar{y})^2}} = \frac{\operatorname{Cov}(\mathbf{x}, \mathbf{y})}{\sigma_x \sigma_y}$$

### Spearman Rank Correlation ($\rho$)

When physical phenomena exhibit nonlinear power-law or logarithmic behaviors, Pearson's linear formulation understates the association. The Spearman rank correlation evaluates the Pearson correlation on ranked variables:

$$\rho = 1 - \frac{6 \sum_{i=1}^N d_i^2}{N(N^2 - 1)}$$

where $d_i = \operatorname{rank}(x_i) - \operatorname{rank}(y_i)$.
