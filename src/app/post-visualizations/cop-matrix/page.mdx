# Coefficient of Prognosis (CoP) & Variance-Based Global Sensitivity

The **Coefficient of Prognosis (CoP) Matrix** is a post-training surrogate diagnostic that evaluates how much variance in each output response is explained by individual input features. Unlike standard $R^2$ metrics that artificially inflate with model complexity, $\operatorname{CoP}$ measures surrogate generalization across cross-validated test sets, providing an unbiased assessment of feature importance and metamodel predictive power.

<KeyTakeaways title="Quick Guide & Key Takeaways">
- **Overfitting Immunity**: A model with $R^2 = 0.99$ on training data can exhibit $\operatorname{CoP} = 0.35$ if it memorized simulation noise. The $\operatorname{CoP}$ value reflects true predictive performance on unseen designs.
- **Total vs. Individual CoP**: Total $\operatorname{CoP}_{\text{total}}$ reflects the overall explainable variance of the surrogate. The matrix cells decompose this total into individual input contributions $\operatorname{CoP}_j$.
- **Physics Verification**: If an input known from domain physics to drive an output has a near-zero $\operatorname{CoP}$, the surrogate requires additional training points or an adjusted model architecture.
</KeyTakeaways>

## How to Read This Plot

### 1. Structure of the CoP Matrix
- **Matrix Body Cells ($\operatorname{CoI}_j$)**: Represent the proportion of response variance attributable to input variable $x_j$ based on cross-validated surrogate predictions.
- **Bottom Summary Row ($\operatorname{CoP}_{\text{total}}$)**: Reflects the overall quality of the trained surrogate. It evaluates how accurately the metamodel predicts out-of-bag validation points.

### 2. Quality Evaluation Benchmarks
- **$\operatorname{CoP}_{\text{total}} \ge 90\%$ (Excellent)**: The surrogate accurately captures almost all physical variance. The model is fully validated for global optimization and reliability analysis.
- **$70\% \le \operatorname{CoP}_{\text{total}} < 90\%$ (Good)**: The model captures dominant physical dynamics. Safe for trade-off exploration and Pareto front extraction.
- **$50\% \le \operatorname{CoP}_{\text{total}} < 70\%$ (Marginal)**: The model identifies general directional slopes but misses local non-linearities. Additional sampling points should be added in high-curvature regions.
- **$\operatorname{CoP}_{\text{total}} < 50\%$ (Insufficient)**: The model fails to generalize. Common causes include insufficient sample size, stochastic noise in simulation meshes, or missing primary physical parameters.

### 3. Step-by-Step Diagnostic Routine
1. **Check the Bottom Row First**: Confirm $\operatorname{CoP}_{\text{total}} \ge 70\%$ before trusting individual feature rankings.
2. **Scan Column Cells**: Identify the dominant driver (in Figure 1, $x_1$ Radius drives $62.4\%$ of Peak Stress, while $x_2$ Blade Angle drives $79.5\%$ of Efficiency).
3. **Verify Physical Consistency**: Ensure that known governing parameters show high importance. If a known physical driver displays near-zero importance, check for input saturation or collinear parameter cancellation.

## Mathematical Formulation

Developed by Most & Will (2008), the **Total Coefficient of Prognosis** ($\operatorname{CoP}_{\text{total}}$) is defined as:

$$\operatorname{CoP}_{\text{total}} = 1 - \frac{\operatorname{SS}_E^{\text{test}}}{\operatorname{SS}_T} = 1 - \frac{\sum_{i=1}^N \left( y_i - \hat{y}_{(-i)} \right)^2}{\sum_{i=1}^N (y_i - \bar{y})^2}$$

where $y_i$ is the actual solver response, $\bar{y}$ is the sample mean, and $\hat{y}_{(-i)}$ is the cross-validated prediction from a surrogate trained *without* observation $i$.

### Individual Feature Importance

The matrix cells combine the Total $\operatorname{CoP}$ with the **Sobol First-Order Sensitivity Index** $S_j$:

$$\operatorname{CoP}_j = S_j \cdot \operatorname{CoP}_{\text{total}}$$

Under the ANOVA-Sobol decomposition:

$$S_j = \frac{\operatorname{Var}_{x_j}\big(\mathbb{E}_{\mathbf{x}_{\sim j}}[Y \mid x_j]\big)}{\operatorname{Var}(Y)}$$

The total-order index $S_{Tj}$ additionally includes all non-linear interaction terms involving $x_j$:

$$S_{Tj} = 1 - \frac{\operatorname{Var}_{\mathbf{x}_{\sim j}}\big(\mathbb{E}_{x_j}[Y \mid \mathbf{x}_{\sim j}]\big)}{\operatorname{Var}(Y)}$$
